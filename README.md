## Thesis

**[Distributed Set Reconciliation Simulator](https://github.com/Vidal322/reconciliation-simulator)** · Rust

A modular simulator for measuring how hybrid Rateless Bloom Filter and IBLT
algorithms behave when replicas diverge. It runs reconciliation across up to 100
nodes over 3 network topologies and reports the bandwidth and round-trip cost of
each approach.
